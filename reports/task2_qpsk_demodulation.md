# 実施内容2 QPSK復調回路

## 目的

実施内容1で生成したQPSK帯域信号に対して同期検波を行い、同相成分と直交成分を復元して情報ビット列へ戻す。

## 方法

受信信号 `r(t)` に `2cos(2*pi*fc*t)` と `-2sin(2*pi*fc*t)` を乗算し、1シンボル区間ごとに平均することで `u_I`, `u_Q` を推定した。その後、推定されたシンボルの象限に基づいてビットを判定した。

## 判定規則

| 条件 | 復元ビット |
| --- | --- |
| `I >= 0`, `Q >= 0` | 00 |
| `I < 0`, `Q >= 0` | 01 |
| `I < 0`, `Q < 0` | 11 |
| `I >= 0`, `Q < 0` | 10 |

## 結果

送信ビット列 `101101110001` に対して、復元ビット列も `101101110001` となり、ビット誤り数は0であった。復調波形は `outputs/figures/task2_qpsk_demodulation_waveforms.png`、復元シンボル点配置は `outputs/figures/task2_qpsk_demodulation_constellation.png` に保存した。

## 考察下書き

雑音や伝搬路応答の影響がない場合、受信信号に送信時と同じ周波数・位相の搬送波を乗算し、シンボル周期で平均することで、基底帯域の同相成分と直交成分が復元される。復元されたシンボル点は理想シンボル点と一致し、象限判定によって元の情報ビット列を誤りなく復元できる。
